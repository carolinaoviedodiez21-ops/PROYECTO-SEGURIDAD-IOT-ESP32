# Diagramas del Proyecto

Esta carpeta contiene los diagramas utilizados durante el desarrollo del sistema de seguridad IoT basado en ESP32.

## Diagrama de Bloques

El diagrama de bloques representa la arquitectura general del sistema y muestra la interacción entre los sensores, el microcontrolador ESP32, los actuadores y los servicios de comunicación utilizados.

Los principales módulos incluidos son:

- Sensor ultrasónico HC-SR04 para detección de presencia.
- Sensor PIR para confirmación de movimiento en el interior.
- ESP32 como unidad central de procesamiento.
- LEDs y buzzer como actuadores de alerta.
- Comunicación Bluetooth con aplicación desarrollada en MIT App Inventor.
- Comunicación WiFi para integración con Gmail y ThingSpeak.
- Alimentación mediante power bank de 5 V.
