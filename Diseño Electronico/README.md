# Diseño Electrónico

Esta sección contiene la documentación relacionada con el diseño electrónico del sistema de seguridad IoT basado en ESP32.

Para el desarrollo del prototipo se realizó el diseño del circuito utilizando herramientas de diseño electrónico que permitieron verificar la distribución de conexiones entre sensores, actuadores y la placa de control.

Los documentos incluidos en esta carpeta corresponden a:

- Esquemático electrónico del sistema.
- Diseño de PCB utilizado como referencia para el montaje.
- Distribución de componentes y conexiones.

El diseño contempla la integración de los siguientes elementos:

- ESP32 DevKit V1.
- Sensor ultrasónico HC-SR04.
- Sensor PIR.
- LEDs de señalización.
- Buzzer de alarma.
- Resistencias de protección y adaptación de niveles.
- Alimentación mediante bateria de 3V.

Estos diagramas fueron utilizados como guía durante la etapa de construcción y montaje físico del prototipo.
