# PROYECTO-SEGURIDAD-IOT-ESP32
Proyecto final de Programación Avanzada. Sistema de seguridad inteligente basado en ESP32 con sensores, Telegram, ThingSpeak y aplicación móvil.
Sistema de Seguridad IoT con ESP32

Proyecto final desarrollado para la materia Programación Avanzada.

Descripción

Sistema de seguridad inteligente basado en ESP32 capaz de detectar posibles intrusiones mediante sensores ultrasónicos y sensores PIR. El sistema integra tecnologías IoT para el monitoreo remoto y envío de alertas.

Características:
- Detección de presencia mediante HC-SR04.
- Confirmación de intrusión mediante sensor PIR.
- Alarma visual mediante LEDs.
- Alarma sonora mediante buzzer.
- Notificaciones automáticas mediante Telegram.
- Registro de datos en ThingSpeak.
- Aplicación móvil desarrollada en MIT App Inventor.
- Comunicación Bluetooth para activación y desactivación.
  
Tecnologías utilizadas:
- ESP32 DevKit V1
- Arduino IDE
- ThingSpeak
- Telegram Bot
- MIT App Inventor
- Wokwi
- Fritzing
