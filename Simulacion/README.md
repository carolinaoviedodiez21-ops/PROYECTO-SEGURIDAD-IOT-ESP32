# Simulación del Sistema

La simulación del sistema fue realizada utilizando la plataforma Wokwi con una placa ESP32 y los componentes principales del proyecto.

Durante esta etapa se verificó el funcionamiento de la lógica de control del sistema de seguridad, incluyendo:

- Detección de presencia mediante sensor ultrasónico HC-SR04.
- Confirmación de intrusión mediante sensor PIR.
- Activación de LEDs de señalización.
- Activación de la alarma sonora mediante buzzer.
- Temporizadores y lógica de confirmación de intrusión.

En la plataforma de simulación las funciones de conectividad IoT (WiFi, Gmail, ThingSpeak y aplicación móvil) no fueron verificadas. Sin embargo, posteriormente fueron implementadas y probadas sobre el prototipo físico.
